# SmartSearch · 联网搜索与调研

检索公开互联网的最新信息，抓取网页正文并整理可追溯的来源证据。适用于查新闻与产品动态、找官方资料和技术文档、比较工具或方案、核验一个说法、阅读并总结给定链接，以及多来源调研。支持联网搜索、公开网页内容提取、站点地图、检索路径规划和深度研究；返回来源 URL、检索提供方与研究摘要，便于继续核对原文。用户说“帮我查一下”“找可靠来源”“这个链接讲什么”“对比并给出处”或“深入调研”时使用。只访问公开网页，实际可用来源取决于服务端已配置的检索提供方。

## 示例场景

- 查找这项技术的最新官方资料，并给出来源。
- 读取这个公开链接并总结重点。
- 比较这些工具，核验关键结论并给出处。

## 插件文件与维护

- `plugin.json`：便携插件清单；`extensions.com.openai.interface` 保存名称、场景描述、示例提示和图标。
- `.codex-plugin/plugin.json`：兼容现有 Codex 插件格式，与便携清单保持一致。
- `.app.json`：引用已注册的个人 App，不包含令牌或 OAuth 密钥；使用者仍需拥有该 App 的访问权并完成授权。
- `assets/plugin/`：实际图标文件与可核对的来源说明。

在支持 GitHub 插件导入的客户端，选择此仓库并以仓库根目录为插件目录。此插件包复用已有 App，不包含新的 MCP 后端，也不扩大其权限。

平台中已创建的 Dev App 可在“设置 → 插件 → 对应插件 → 管理应用”编辑名称和描述。当前页面只提供这两项和工具刷新，没有图标上传控件；仓库清单中的图标用于从仓库安装的插件，不能当作旧 Dev App 云端图标已发布的证据。

更新展示信息时同步两份清单并保持 `.app.json` 的 App ID；无需重新创建 App 或变更 OAuth 配置。官方格式参考：https://developers.openai.com/codex/plugins/build/
